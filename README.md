## Cześć, tu Marta! 👋

Absolwentka psychologii na UW z doświadczeniem w analizie danych i automatyzacji procesów. Buduję swoją ścieżkę w praktycznym cyberbezpieczeństwie. Naturalne zainteresowanie socjotechnikami i phishingiem wykorzystuję do analizy czynnika ludzkiego (Human Factor).

Wierzę, że najłatwiejszym punktem wejścia do każdego systemu jest (niestety) **ludzki system operacyjny**. Łączę twarde umiejętności inżynierii danych i umiejętności analityczne z psychologicznym zrozumieniem mechanizmów manipulacji oraz analizy behawioralnej.
